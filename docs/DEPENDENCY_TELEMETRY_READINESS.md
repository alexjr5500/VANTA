# Dependency telemetry

Opt-in VANTA_DEPENDENCY_TELEMETRY_ENABLED=true starts one sample/minute after HTTP startup. PostgreSQL SELECT 1 through the existing Prisma pool measures wait and round-trip combined, not pool occupancy. Redis cache PING uses the existing connection; realtime adapter checks connection state only, not delivery. Disabled dependencies are explicit. No new connections. A 2-second deadline bounds each reported probe; timed-out underlying work is not canceled but no further command is submitted until it settles. Over 250ms on a successful check is slow. Two degraded samples emit one process-local alert, and a healthy sample emits recovery. Logs include only aggregate statuses and durations. Timers are tracked by BackgroundDrain. Central routing, dead-process detection, pool occupancy metrics and isolated live outage tests are not yet configured. Production flags unchanged.
