# Coin-funded verification purchases
Isolated sandbox only. Requires VANTA_SHOP_SANDBOX_ENABLED=true, VANTA_COIN_PAYMENT_MODE=test, VANTA_SHOP_COIN_BADGE_ENABLED=true, non-production isolated database and a wallet PIN. Price follows the canonical 100 coins/USD rule; no purchase bonus or creator earnings credit. Debit and entitlement creation occur in the same serializable transaction. Reserved coins cannot be spent. No automatic renewal, existing active or suspended entitlement replacement, or expired/superseded badge refund is supported by this rail. Admin reversal of an eligible active badge reverses the original payer debit and revokes the recipient entitlement atomically. Verify concurrency, rollback, wallet PIN lockout, refunds, gifts and device flows on staging before enabling any production variant. Google Play Billing is intentionally deferred.
